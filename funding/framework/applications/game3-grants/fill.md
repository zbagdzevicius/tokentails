## 14. Why Web3 Gaming? *

`why_web3` · longtext · 609/900 chars · ✓ · from answer · facts F-025, F-007, F-020

```text
Each rescued cat is an on-chain asset held in a Stellar wallet the game creates for every player, so ownership works without asking a casual player to install a wallet first. That design already carries real use: the production Cat contract has processed 1,218,693 invocations since January 2025. On-chain records make the link between a game character and a real shelter cat public and checkable, and the same rails let players pay in XLM or USDC next to card and in-app payments. The grant work keeps every generated level and story tied to its on-chain cat, so a shelter can see what was made from its cat.
```
