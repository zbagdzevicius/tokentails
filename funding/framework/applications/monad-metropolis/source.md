- Submission: working product with a public project profile, demo video, short written description, code link (verifiable during the six-week build period).
- New work: existing projects are fine if "the work you submit is new"; "what you show on 13 Oct should have been built during the six weeks".
- Judging criteria: not on the public page. Winners per track plus an overall grand champion.
- Eligibility: online, global, solo or teams; country restrictions in the official rules.
