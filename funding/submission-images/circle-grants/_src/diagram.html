An AI agent pays an animal shelter
Two HTTP requests, one payment, one public split. The agent needs no bank donation flow: it pays USDC on Arc, and ShelterSplit pays the shelter in the same transaction.

1

Ask for a shelter cat card

GET /shelter/agent/cat-card

The API answers 402 Payment Required: a price in USDC, the ShelterSplit address to pay, and a one-time memo that expires in 10 minutes.

2

Pay in USDC on Arc

The agent calls donate(memo) with USDC, Arc's native gas coin, so it needs no other token.

Standard x402 clients can pay with the exact scheme through a facilitator instead.

3

Split in the same transaction

One public NativeDisbursed event per shelter, carrying the memo. The contract keeps no balance.

Retry with the receipt

The agent sends the transaction hash in X-PAYMENT. The API reads the receipt from Arc, checks the memo, and accepts each nonce and transaction once.

It returns the card: the cat's name, portrait and shelter.
