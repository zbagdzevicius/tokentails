An agent pays a shelter. It gets a cat card back.

x402-style flow on /shelter/agent/cat-card. No human in the loop, no facilitator: the server checks the payment against the chain itself.

1

Ask

Agent → Token Tails API
GET /shelter/agent/cat-card 402 Payment Required scheme onchain-receipt network eip155 · Arc payTo ShelterSplit memo x402:<nonce>

The offer names the price, the contract to pay and a one-time memo.

The agent's own budget
env, set by its owner MAX_PRICE_WEI default 0.01 USDC

From the open example, examples/agent-pay.mjs

2

Pay

Agent → ShelterSplit on Arc

It checks the price against its own cap (payAndFetch refuses anything above it), then calls donate(memo) with native USDC.

ShelterSplit splits it to every shelter wallet in the same transaction: one public event per payout. The contract keeps nothing.

3

Prove

Agent → Token Tails API
GET /shelter/agent/cat-card X-PAYMENT: tx hash + nonce

The server reads the receipt over RPC:

  • status ok
  • payouts from that contract with that memo sum to the price
  • nonce issued by us, not expired
  • tx hash never used before
