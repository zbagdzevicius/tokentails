# Catnip Heist on Anitya: submission kit

Everything here is generated by `npm run export-glb` (in `catnip-heist/`) from the game's own
levels and sprite sheets. No 3D editor work is needed. The human steps are logging in, importing
one file, pressing Publish and pasting a post. Budget about 10 minutes per world.

Researched on 2026-09-29. Re-check the Discord before each deadline, because rules and weekly
challenges are announced there first.

## 2. The kit (limits enforced by the exporter; details in `manifest.json`)

The exporter checks these limits: world at most 20 MB, 500k triangles and 20 lights; each character
or prop at most 5 MB and 100k triangles; everything together at most 250 MB. It exits 1 if any file
breaks one. Every file is also loaded back through GLTFLoader, both in the page and in
`tools/export-glb.test.ts`.

Scale: 1 game tile = 3 m, so the walls are 2.4 m high and a visitor's avatar fits the corridors. Each
file is centred on x/z, with the floor at y = 0 and the character fronts facing +Z. In every world
all doors are open, so it can be walked. The crate with the shelter cat still stands closed as the
centrepiece.

The rest of the kit:

- **Characters:** 58 static cats and 5 static guard dogs (55-260 KB each). There are also
  flipbook-animated versions: IDLE and WALKING for the crew cats (Bob, Oreo) and the 8 shelter cats,
  and WALKING and SNIFFING for the 5 dogs (1.6-2.6 MB each).
- **Props:** shelter crate, key, vault door, plate door, pressure plate, exit portal, catnip coin and
  checkpoint paw (10-125 KB each).
- **Screenshots:** `previews/<world>.png` (overview) and `previews/<world>-crate.png` (the
  centrepiece), rendered from the reloaded GLB. Attach two to each Discord post.
- **Total:** about 64 MB for all 94 files. One world with its full kit is about 20 MB. Upload only
  what a world uses, because free storage is 250 MB.

## 3. Human steps (about 10 minutes per world)

1. `cd catnip-heist && npm run export-glb` (about 1 minute), if the files are not there already.
2. Open https://app.anitya.space and log in (the free account). Create a new world.
3. Drag `worlds/<file>.glb` from `catnip-heist/export/anitya/` onto the builder (Assets panel). Set
   its position to 0, 0, 0. Place the spawn point on the floor inside the first room. (2 min)
4. Every world, the main jam included (immersion is 60% of the score, and a static walk-through
   with open doors does not deliver what the post promises): make it playable by typing, not editing. Open the builder's AI or Magic Box
   ("New logic") and paste the prompts in section 5 (5b for heist-08). Test the rules once in play mode. (5 min)
5. Press Publish and make sure the world is on the **public feed**. Copy the URL. (1 min)
6. In the Anitya Discord, go to `#jam-submission`, press 📥 Submit and pick the round. Paste the post
   from section 4 and attach the two preview PNGs. (2 min)

Optional scripted import (step 3): `node tools/export-anitya-upload.mjs --world=heist-08 --live`
opens a visible Chromium with a saved profile at `export/anitya/.pw-profile/` (gitignored). You log
in there once. The script then waits for the builder's file input and gives it the GLB (add `--kit`
for the props and animated characters). It never clicks Publish. With no `--live` flag it is a dry
run that only lists the files. It was tested against a local fixture page only, never against the
live site. Anitya's DOM is undocumented, so if no file input appears within 10 minutes it says so,
and you drag the file in by hand instead.

Optional chat-driven editing: add the Anitya connector in Claude (Settings > Connectors > Add,
`https://ais.anitya.space/mcp`). Keep `app.anitya.space/builder` open and set both tool groups to
"Always allow". Claude can then place the imported assets and add logic from chat. It cannot publish
for you, and it cannot upload files.

## 5. Prompts for the Anitya AI (Challenge 2 playability)

Paste these one at a time. Each one is short, because the connector guide says one short line
corrected live works better than a long prompt:

1. "Make the wooden crate in the centre a goal. When the player touches it, show 'You freed Mochi!'
   and play a win sound."
2. "Make the green catnip leaves collectible. Show a counter 'Catnip: n / 20' at the top."
3. "Make the dogs walk back and forth along their corridor. If a dog touches the player, send the
   player back to the start."
4. "Add a start message: 'Kibble Corp caged Mochi. Sneak past the dogs and open the crate.'"

### 5b. Prompts for heist-08 (main jam)

1. "Make the key collectible. The vault door stays locked until the player holds the key; then it
   opens."
2. "Make the wooden crate behind the vault a goal. When the player touches it, show 'You freed
   Clover!' and play a win sound."
3. "Make the five dogs walk back and forth along their corridors. If a dog touches the player, send
   the player back to the start."
4. "Make the green catnip leaves collectible. Show a counter 'Catnip: n / 26' at the top."
5. "Add a start message: 'Kibble Corp caged Clover in its HQ vault. Find the key and sneak past the
   dogs.'"

## 6. Before you post: checklist
