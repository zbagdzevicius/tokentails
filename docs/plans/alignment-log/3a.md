## Interpretations (please review)

1. `requireAccount` resolves on `isGuest !== true` (not strictly `=== false`): a pre-backfill document has no field and is a real account. Transient profiles never count.
2. A guest (anonymous user) whose profile request fails keeps playing on the template; the non-dismissible profile-error sheet is only for signed-in users. Otherwise a backend outage would wall guests again.
3. Forced views (verification, profile error, conflict, fallback) open by themselves only on `/game` or while a `requireAccount` is waiting; optional pages never force a modal.
4. "Within 5 s an interactive canvas": the spec asserts the lobby is playable (PLAY visible, pill shown, no dialog) within 5 s of tapping PLAY GAME in CI, then that a mode boots a canvas. The local dev server compiles on demand (and while other tasks edit files), so locally the bound is 15 s; measured 1.1 s to commit, about 9 s to a playable lobby while "Compiling" was shown.
5. Conflict state copy: after a guest linked an identity whose email already has an account, the backend merge endpoint needs an anonymous guest token, which no longer exists; the sheet offers "Sign in to my account" and a support link instead of an automatic merge.
6. Support link: `mailto:hello@tokentails.com` (the backend's default sender). Change it if another inbox is monitored.
7. Merge failure (409, the 30-day limit) or a network error after sign-in shows "You're signed in" with a note; the account is usable. A retryable failure (network, 5xx, 403 EMAIL_UNVERIFIED) keeps `{guestToken, expiresAt}` in sessionStorage (`tt.pendingMerge`, `context/auth/pendingMerge.ts`) and runs the merge again on the next ready account profile in this tab (after a reload, after the email is verified). The anonymous user is gone by then, so the token cannot be refreshed: the retry works for up to an hour, and the copy says exactly that ("while this tab stays open, for up to an hour").
8. The sheet title follows the reason the interceptor derives from the route (#64). The fallback, and the forced views on `/game` with no waiting caller, use `sign-in` ("WELCOME TO TOKEN TAILS"), not "SAVE YOUR CAT".
