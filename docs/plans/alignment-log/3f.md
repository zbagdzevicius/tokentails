### Data: `client/api/impact-api.ts`, `client/hooks/useImpact.ts`, `client/public/impact/snapshot.json`

- `loadImpact`: CDN `impact/impact.json`, then `GET /impact`, then the bundled baseline. Each source
  gets one try with a 3 s abort. A 429 is never retried: that source is skipped until its
  `Retry-After` (default 5 min). A caller abort rejects.
- `normalizeImpact`: only `_v: 1` with a valid `generatedAt`; every field the UI reads is filled
  with a safe value, bad ISO codes and non-integer amounts are dropped.
- `loadImpactForPage(isApp)`: web uses the chain; app builds read only the committed baseline.
- `useImpact({ initial, refetch })`: renders `initial` at once. Default refetch: no initial, or an
  app build. Never replaces live data with the older baseline. Aborts on unmount.
- CDN URL: `NEXT_PUBLIC_IMPACT_URL`, default
  `https://tokentails-nfts.fra1.cdn.digitaloceanspaces.com/impact/impact.json` (the backend writes
  `impact/impact.json` at the bucket root; the bucket name is an assumption, see limitations).
- `client/scripts/snapshot-impact.mjs` writes the baseline from `IMPACT_SOURCE_URL` (default
  `http://localhost:3005/impact`) with `_baseline: { stampedAt, from }`. It refuses a non-v1 body or
  any private key name (email, wallets, walletPrivateKey, users, password, token, firebaseUids).
  `--check` validates the committed file. The committed baseline was written from the local
  backend on 2026-10-01.
