## Limitations and notes

- The landing mounts the 6d reel (`GameplayReel`) right after the hero, only while
  `hasReelClips` is true (review fix 2).
- Standalone Heist exports: only the tokentails.com build (`HEIST_BASE=/heist-game/`,
  `build:client`) keeps the shared `/favicon.ico` and `/icons/*` links. Every other base (plain
  `npm run build` for itch, Poki, Anitya; the Pages workflow; dev) swaps them for the game's own
  `assets/images/paw.png` at build time (`iconLinksFor` in `catnip-heist/vite.config.ts`, review
  fix 4).
- The crew CTA spells out names up to 10 characters (`CREW_CTA_MAX_NAME`) and shows "YOUR CAT IS
  WAITING" for longer ones, since the pixel button never wraps. Below `sm` it is no longer scaled
  up and is capped at `100vw - 2rem`. The Playwright spec checks a 10- and a 16-character "W" name
  at 360 px (review fix 1).
- Maskable icon: the coin runs to the source's bottom edge, so shrinking a bust that sits on the
  edge (the review's 0.66) cannot bring the coin inside the safe circle. The maskable bust is now
  `scale 0.64` and lifted `0.12` off the edge (`MASKABLE_BUST`), with a flat base below the coin;
  `check-meta.test.ts` asserts no ears, face or coin pixel falls outside the 80% circle.
- `docs/CLIENT.md` (outside my list): I added a fixed and known-issues block for icons, meta and
  the landing CTAs.
