Plan sections: G6 (Problem, Solution and Acceptance, except the overlay migration, which is W4), F3.1,
G14 theme-color, the G8 `CatnipIcon` and copy items, decisions #45, #47 and #56. Known bugs fixed: zoom

## What was built

### Scope gating (G6 "Scope gating", "Viewport")

- `client/components/shared/skyScope.ts` holds the route list in one place. It exports `NIGHT_ROUTES`
  (`/`, `/packs`, `/shelter-payouts` and its subpaths, `/impact`, `/heist`, `/game`), `skyForPath`,
  `isZoomLocked`, `viewportForPath` and `applySkyScope`.
- `pages/_document.js`:
  - `getInitialProps` writes `data-sky="night"`, and `data-zoom="locked"` on `/game` only, into the
    server HTML. Static export works too, because it reads `ctx.pathname`.
  - An inline `#tt-first-paint` style paints night-900 before the CSS loads.
  - `theme-color` is now `THEME_COLOR` (`#0b0820`), replacing `#1f2937`.
  - The viewport meta has moved out of this file.
- `pages/_app.tsx`:
  - Renders one keyed viewport tag (`next/head`) from `viewportForPath`. Every route gets
    `width=device-width, initial-scale=1, viewport-fit=cover`. Only `/game` adds
    `maximum-scale=1, user-scalable=no`.
  - On every client-side navigation it re-applies `data-sky` and `data-zoom`.
  - Mounts `NativeChrome` (client only).
- `styles/globals.scss`:
  - The global background is night-900; `@apply bg-gray-900` is gone.
  - `text-gray-800` now applies only under `html:not([data-sky])`.
  - Cream ink and `color-scheme: dark` apply only under `html[data-sky]`.
  - `touch-action: pan-x pan-y` used to block pinch zoom everywhere. It now applies only under
    `html[data-zoom="locked"]`.
  - The dead `[data-testid="modal-content"]` override (`globals.scss:230-232`) is deleted.
- `layouts/MainLayout.tsx`:
  - Removed the "DISABLE iOS Pinch to zoom" double-tap preventer. It registered its own factory as
    the listener, so it never did anything.
  - `<main>` keeps `text-yellow-900` for out-of-scope routes. Under `[data-sky]` it switches to
    `text-tt-gold-ink` through the `[[data-sky]_&]:` variant.
  - Surface ink (review fix, see "Review fixes"): `globals.scss` gives dark panels (`bg-black/40`
    and up, `bg-tt-night-*`, `bg-gray-800`/`900`, ...) cream ink and light panels (`bg-tt-cream`,
    `bg-white`, pastel 50-300) gold ink, inside `[data-sky]` only, at zero specificity.
- Verified on live :3001:
  - `/`, `/game`, `/packs` and `/shelter-payouts` get `data-sky=night`, cream ink and the dark colour
    scheme.
  - `/feed` and `/stats` get no `data-sky`, gray-800 ink and the normal colour scheme.
  - Every route gets night `body` background and theme-color `#0b0820`.
  - Client navigation feed -> packs -> game -> feed sets and clears both attributes and the viewport

### CatnipIcon (G8, decision #56)

- `client/components/shared/CatnipIcon.tsx` takes `size: 16|24|32|48|64|96`, `className?` and `alt?`.
  - It uses an exact device-pixel srcSet,
    `/catnip/catnip-v2-{s}.png 1x, -{2s}.png 2x, -{3s}.png 3x`, served from `client/public`, not the CDN.
  - The CSS size is fixed in px (not rem), so each density maps 1:1 onto the file's pixels. There is
    no `.pixelated` class.
  - `alt` defaults to "Catnip". `alt=""` marks it decorative and adds `aria-hidden`.
  - `CATNIP_ICON_FILES` lists every file the component can request.
- Every DOM use of `logo/catnip.webp` in my files is replaced. All of them sit next to a visible
  "catnip" label, so they are decorative:
  - `GameStatsSection` (lobby HUD): 16
  - `ProfileModal`: 16
  - `EndGameModal` score line: 24, via `icon: "catnip"`
  - `GameSelectModal` Paw Match preview tiles: 16
- Copy (G8): the Codex "CLAIMABLE STASH" tile is now "CLAIMABLE TREASURE", and "Legendary stash" is
  now "Legendary bonus". (Corrected in review 3: earlier only "Legendary bonus" had landed; the tile
  title and its theme key now share `CLAIMABLE_TREASURE_TITLE` so they cannot drift apart again.) The backend fields
  (`legendaryStashBonus*`) are unchanged.

### Lobby v0 and Snowfall (G6 "Lobby", decision #47)

- **Dusk grade.** `--tt-sky-dusk` (`globals.scss`) layers three things, all built from tokens:
  - a soft night vignette;
  - a horizon glow at the lobby ground line (about 54% of the viewport at 390 and at 1440);
  - a night -> dusk-top -> dusk-mid -> horizon ramp.
- `[data-sky="dusk"]` applies it to any container. `constants/hooks.ts` `useBackground` returns
  `var(--tt-sky-dusk)` for the Shelter lobby, replacing the hot-pink `bg-10.webp`.
- Every scene background now has a night colour behind its image, so a slow image never shows a gray
  frame. G7 replaces this in W6.
- **Snowfall** is now a seasonal toggle, off by default.
  - Turn it on for a season with `NEXT_PUBLIC_SNOWFALL=on`, or by listing month-day windows in
    `SNOWFALL_SEASONS`. Year wraps work.
  - It never renders when the viewer prefers reduced motion; this uses `useSyncExternalStore`, and
    the server snapshot is "reduced", so hydration is safe.
  - It is now `aria-hidden`.

### Palette guard (`client/scripts/check-palette.mjs`, `npm run palette:check`)

- **Rules:**
  - `overlay-cream`: a full-screen overlay with `bg-yellow-300` or `bg-tt-cream`. An overlay is
    `fixed` plus `inset-0`, `inset-x-0 inset-y-0`, `top-0 left-0 right-0 bottom-0`, or `top-0 left-0`
    with `w-full h-full` / `w-screen h-screen`. Classes are joined per `className={...}` expression
    and per `clsx`/`cn`/`classNames`/`twMerge`/`cx` call, and a file-level `const NAME = "..."` used
    there is expanded (review fix #4).
  - `overlay-white`: the same overlay with `bg-white`.
  - `overlay-z`: the same overlay with an arbitrary `z-[N]`.
  - `night-hex`: a NIGHT hex literal outside `design/tokens.ts` and `styles/tokens.css`. The script
    reads the NIGHT values from `tokens.ts` at run time.
- Never scanned: `public/` (and so the Heist build) and `heist-game`.
- Allowlist: `client/scripts/check-palette.allowlist.json`. Each entry has a `max` count (default 1):
  one finding over it fails, the report lists it under `exceeded`, and an entry with fewer findings
  than `max` is listed under `slack` (review fix #5).
  - 14 modal overlays from the plan's W4 list, plus `PackModal` and `TailsCardModal` (spelled
    `fixed top-0 left-0 w-full h-full`, found once the guard read that spelling): `overlay-z`, until task 4d.
  - 3 reveal and effect overlays: `OpeningAnimation`, `RevealAnimation`, `Celebration`.
  - `CrashPanel.tsx` `night-hex`: the owner should import `THEME_COLOR`.
  - `capacitor.config.ts` `night-hex`: permanent, pinned by a test.
  - Unused entries are reported as stale.
- Current result: 357 files, 0 findings, 27 allowlisted findings across 22 entries. It runs in warn mode; task 4d tightens the
  allowlist and task 7b makes the check blocking.
- CI: I added one step, `Palette guard (warn)`, to the `bundle-guards` job in
  `.github/workflows/ci.yml`. This is outside my files, so it is listed under "Outside my files".
