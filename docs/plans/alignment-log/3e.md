## A. Typography call sites (G12)

- **Every scene gates on fonts.** `preloadTTFonts(this)` is the first statement of `preload` in
  Match3Scene, CatnipChaosScene, PixelRescueScene, ShelterScene and BaseScene.
- **Paw Match HUD.** New pure module `components/Match3/hudLayout.ts` computes the board and one slot
  box per HUD text for three modes (standard: normal, compact or tight; wide; small landscape).
  `Match3Scene` creates every HUD text with `ttText` roles in its slot (`hud`, `label`, `burst`),
  and one `layoutHud()` re-positions, refreshes resolution and `ttFit`s every text. It runs on
  create, on `TT_FONTS_HEALED` and on `LOOK_RESIZE`. `setHudText` refits after each update.
  - Pixelify Sans (5 sites) is gone; those labels use `label` (decision #92).
  - The streak line is prioritised segments (`BEST` drops first, then `W{n}`, then the bonus
    seconds, before shrinking), separator " • ".
  - Overlaps fixed: on phones the streak line sat on the stat cards; the score and best lines
    collided; small-landscape side panels sat under the board frame. Phones keep 56 px beside the
    title plate for the DOM close button. Short phones (667/640 px) use a tight stack.
  - `px(n)`: 2e's `fitCssCamera` maps CSS pixels onto the dpr backing store, so the coordinates stay
    CSS px and the texture resolution (`ttResolution`, camera zoom x ratio, capped at 3) carries the
    device ratio. Multiplying coordinates by the ratio as well would double every size. Logged as an
    interpretation of the plan wording.
  - Special-tile markers are vector badges (`drawPowerMarker`, Graphics), not monospace glyphs, so
    they need no font and stay crisp.
  - The first-move tutorial text uses the `hint` role (decision #80), wraps inside its panel and the
    panel grows to fit. Copy "First move: drag between the glowing tiles" (no "tokens", R9).
    Placement, hiding combo/mission during it, and the pointer are task 5c (not reworked).
  - `render_game_to_text()` now includes `hud` (each text's bounds, family, size and slot) and
    `hudMode`, for e2e overlap checks.
- **Cupid Cat (PixelRescue).** Arial Black bursts (3 in the scene, 3 in `BasePixelEnemy`) use the
  `burst` role; the CatCrate label uses `label`; TutorialManager uses `hint` and the CDN pixel font
  load is deleted (#80). New helper `components/Phaser/typography/worldText.ts`
  (`ttWorldText`, `cameraCssZoom`, `scaleTo`) rasterises at the CSS size and scales by the camera's
  CSS zoom, so role minimums are CSS pixels in a zoomed world. Scale tweens use `scaleTo`. The
  ⚡ emoji in "⚡ STUNNED! ⚡" was dropped (no brand face has it).
- **Wheel** uses `ttCanvasFont("title", 48/40)` and redraws once `loadGameFonts()` settles.
- **shareCard** awaits `loadGameFonts()` (`downloadShareCard` is now async), and uses `hud`, `title`,
  `caption` roles; the tx hash line is `code`.
- **portrait.tsx** (#82): headings use `font-primary` (Passion One), body inherits the html Nunito
  stack; the Space Grotesk / Plus Jakarta Sans constants are gone.
- **Pixel fonts deleted** (#81): `client/public/pixel-rescue/fonts/pixel-text{,1,2}.ttf`.
- Acceptance grep `Pixelify|proxima-nova|Arial|monospace` over `client/components` and `pages`
  outside typography: only `shared/auth/BrandSignInButton.tsx` (Roboto/Arial and the Apple system
  stack the Google and Apple brand rules require; G9's file).
