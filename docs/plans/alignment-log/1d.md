## Built

- `client/components/shared/PixelButton.tsx`: `size: 'sm' | 'md' | 'lg'` (default `md`), `fullWidth`,
  `type` (default `button`), `icon` (PixelIcon name), `busy` (inline spinner, `aria-busy`, clicks
  ignored), `disabled`, `as: 'button' | 'span'`, clsx class building. Inner markup is spans, so the
  button is valid HTML both as a `<button>` and as a `<span>` inside a link. One shared, lazily
  created pair of click/hover `Audio` elements instead of two per mounted button. `onClick` is still
  called with no arguments (see decisions).
  - Fixed: inline `width: "100% !important"` (React drops it) removed, `w-full` class used instead;
    `false`/`undefined` class tokens gone; stray `'` in the label row class gone.
  - Legacy props `isSmall`, `isMedium`, `isBig`, `isWidthFull`, `isDisabled` are removed; the codemod
    left zero uses and `tsc` is green.
- `client/components/shared/PixelIcon.tsx`: inline SVG, `aria-hidden` by default, `label` gives
  `role="img"` + `aria-label` + `<title>`, `size` defaults to `1em`, `currentColor`, crisp edges.
- `client/components/shared/icons/pixelarticons.ts`: generated path data for 21 pixelarticons
  glyphs (MIT, 2.4.1). `client/components/shared/icons/custom.ts`: hand-drawn fallback
  (`messenger`, which pixelarticons lacks).
- `client/scripts/codemods/sync-pixel-icons.mjs`: regenerates `pixelarticons.ts` from
  `node_modules/pixelarticons` (or `--from <dir>`); `--check` fails when stale. Checks the licence is
  MIT and every glyph is on the 24x24 grid.
- `client/scripts/codemods/pixel-button.mjs`: TypeScript compiler API codemod, `--dry` prints
  per-file and total counts. Rewrites PixelButton `isSmall`/`isBig` -> `size`, `isWidthFull` ->
  `fullWidth`, `isDisabled` -> `disabled`; also `Tag isSmall`, `Countdown isBig`, `Snowfall isSmall`
  (their own boolean size props, also in owned files). `={expr}` becomes
  `size={expr ? "sm" : "md"}`, `={false}` is dropped; unsafe cases are listed as MANUAL.
  Run result: 29 files, 96 rewrites (PixelButton.isSmall 44, Tag.isSmall 26, PixelButton.isDisabled
  13, PixelButton.isBig 6, Countdown.isBig 5, PixelButton.isWidthFull 2), 1 MANUAL
  (`GameSelectModal.tsx` `isMedium={isMediumScreen}`, converted by hand to
  `className="md:scale-[1.35] md:hover:scale-100"`, same breakpoint as the JS check and the same
  shrink-on-hover as before; the first pass grew it to 1.4 on hover, reverted after review).
  Diffs reviewed by hand, including the two `size={... ? "sm" : "md"}` ternaries.
- `Tag`, `Countdown`, `Snowfall` take `size` instead of booleans.
- Links wrapping a PixelButton in owned files now use `as="span"` (CatsHub x2, TeamSection,
  MarketplaceItemDetails, ShelterBenefits, Stats, pages/index, pages/old-landing, Footer).
- boxicons: all 26 `bx` uses replaced.
  - Five modals (Invite, Profile, Codex, Quests, Support) had an invisible, unlabelled duplicate
    close button next to `CloseButton`. It was the only focusable close (`CloseButton` is an

  - SignIn: Password button gets the key glyph (was the Apple glyph), Apple keeps an apple glyph,

  - Share/ShareModal: facebook, messenger (hand-drawn), copy. Blog loaders: loader, bookmark,

  parts containing a boxicons class (`bx`, `bx-*`, `bxs-*`, `bxl-*`, `bxx-*` as whole words).

## Bugs found and fixed on the way (not in section 7)

- A busy or disabled PixelButton now calls `preventDefault()` on click whatever `as` is, so a
  `busy` `type="submit"` button no longer resubmits its form (a busy button is not natively
  disabled). The spinner stops under `prefers-reduced-motion` (`motion-reduce:animate-none`). The
  shared click/hover sound rewinds (`currentTime = 0`) before `play()`, so two quick clicks are both
  heard.

- PixelButton rendered without `type`, so inside a form it was a submit button: SignIn's
  "I FORGOT PASSWORD" also submitted the sign-in form. Default is now `type="button"`.
- `ToastProvider` passed a new context object every render, so `useToast()` returned a new
  function on each toast and any effect depending on it re-ran (an infinite loop in a test that
  fires a toast from an effect). The value is memoised.
- `Countdown`'s `isBig` local was renamed `isLarge` (internal).

## Decisions applied

- #63 icon source: `pixelarticons` (MIT confirmed from the package's LICENSE, v2.4.1), with a
  hand-drawn fallback folder. Path data is copied into the repo by a generator instead of importing
  `pixelarticons/react` at runtime: no SVG loader, no ESM transform in jest, only used glyphs ship.
- Sizes keep the existing visual scale (`sm` = scale 0.675, `md` = 1, `lg` = glow + 1.25/2) rather
  than new box sizes, because many call sites compensate the scale with negative margins
  (`-mt-2`, `-mb-4`); changing box size would shift those layouts. `isMedium` (one use) became a
  responsive class instead of a fourth size.
- `onClick` keeps its zero-argument call: `EndGameModal` and `PixelRescueEndGameModal` pass
  `(nextLevel?: string) => void` handlers, which would have received the click event.
- The plan names jscodeshift; the task says TypeScript compiler API (no new deps). Used the latter.

   (plain `<a>` for a full page load into the game shell, a `ref` for the TeamSection CTA, an
   external `target="_blank"` map link, Next `Link` in the static export); one `href` prop would
   need all those modes and still could not make a focused link inert without removing it. An inert
   CTA is a plain `<PixelButton disabled />`. No caller changed (none passed busy/disabled).
   Test: `@ts-expect-error` on both props plus a runtime check that the span adds no aria state and
   never blocks the link.
2. Hover sound on touch (valid): `onPointerEnter` plays only when `pointerType === "mouse"`. Tests
