In May 2024, Token Tails joined Microsoft for Startups, Microsoft's support program for early-stage companies. It was a place in a program, not a partnership: the program is not an investment, and Microsoft did not co-develop the game.

## What the program gave

Microsoft for Startups gives young companies credits for Microsoft's Azure cloud and AI services, plus technical guidance. Token Tails joined while building its first cat game, and the support it named at the time was Azure cloud and AI tooling for that game.

## A note on the original post

The first version of this announcement called it a partnership with Microsoft and included a quote we cannot confirm word for word. We have corrected the framing and removed the quote.

## Update, October 2026

Token Tails now makes several free cat games, including [Catnip Heist](/heist) and [the main game](/game), tied to Pink Paw, a cat shelter in Kaunas, Lithuania. Since October 2026 it pays the shelter through open-source contracts, and each payout is public at [/shelter-payouts](/shelter-payouts). The whole story, from 2024 to today, is in [The Token Tails story](/feed/news/token-tails-story).
