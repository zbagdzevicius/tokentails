# Art sources

Authoring files moved out of `public/` (plan G7) so they are no longer served or shipped in app
builds: `Sprite-0001.aseprite`, `bird.aseprite`, `tilemaps.aseprite` and `base.tmx`. Nothing loads
them at runtime. Tiled's `base.tiled-session` (editor state with another machine's absolute paths)
was deleted rather than moved: session files are not art sources and should not be committed.
`base.tmx` points at `../../public/base/blocks-original.png`, which was already missing
before the move (the runtime sheet is `public/base/blocks.png`).

The runtime night skins, plates and look manifest are generated by `client/scripts/art/build.mjs`
from the shipped sheets and the landing hero; see `client/art/palette.json` for the palette.
