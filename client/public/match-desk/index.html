Motored.lt, a related-party sponsor (founder's company), will match public gifts to Pink Paw (Rožinė pėdutė) on Arc once its match vault is deployed and funded. Claude will propose each match, code will check the amount against the written policy, and a capped contract will pay it.

Read this first

  • Motored.lt is a related-party sponsor (founder's company). It is not an outside or independent sponsor.
  • The wallet of Pink Paw (Rožinė pėdutė) is still held by Token Tails until the handover. Matched money reaches that wallet. The shelter does not control it yet.
  • The contract caps each gift and each UTC calendar day. The day resets at 00:00 UTC, so up to 2x the daily cap can go out across midnight.
  • The agent's code enforces the per-donor limit. The contract does not.
  • This statement is not a tax receipt.
  • We use USDC on Arc (Arc's native coin). We do not use Circle Wallets, Paymaster or Gateway.
  • Claude proposes. Code recomputes the amount and refuses a proposal that differs. The contract has the last word.
  • A match counts only once its AgentGift event has been read back from the chain (reconciled).
