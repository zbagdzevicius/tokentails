ShelterSplit Rail · MIT · no dependencies

Any game can add a shelter button.

One script tag gives players a gasless "Give to the shelter" button and a live meter read straight from the chain. The gift goes from the player's wallet to the shelter's wallet. No account and no gas: a relay pays the gas but never holds the gift, and the contracts pass it on in the same transaction. See the disclosure below about who holds Pink Paw's wallet today.

Try it

Pink Paw (Rožinė pėdutė)Showcase shelter on the rail

Needs a browser wallet on Arc testnet with test USDC from the Circle faucet. Signing costs no gas.

How the money moves

  1. The player signs once. One USDC ReceiveWithAuthorization (EIP-3009). No gas, no approve, no transaction from their wallet.
  2. A relay submits it. It pays the gas but cannot change the amount, the memo or the payee: the nonce is bound to the router and the memo.
  3. The DonateRouter pays the shelter. It pulls the USDC and splits it through ShelterSplit to the shelter wallet in the same transaction.
  • The router has no owner and keeps no balance.
  • It reverts if any part of a gift would reach the split's treasury.
  • Every payout is a public event; the “Shelters received” total in the Try it panel reads them live.

For AI agents: standard x402

The Token Tails cat-card endpoint answers 402 Payment Required with the standard x402 exact scheme. Its payTo is the shelter's own wallet: the agent signs one USDC transferWithAuthorization, a facilitator settles it and pays the gas, and the agent gets an adoptable-cat card back.

Works with the rail's SDK in one call: payAndFetch(url, { maxAmountBase: 10000n, provider }). Standard x402 clients: the off-the-shelf x402-fetch client reads the offer, signs it and passes the public facilitator's verify step on a testnet; a full settlement through that facilitator is still being tested. On mainnet the scheme opens once the shelter holds its own wallet key.

Disclosure: Pink Paw's wallet was created by Token Tails and is held by Token Tails on behalf of the shelter until handover. The contracts are non-custodial; that wallet is not yet. This page uses testnet tokens with no real value.
