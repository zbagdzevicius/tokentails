# Token Tails Admin CMS

Next.js 16 operations console for shelters and staff: shelter cats, custom blessings, shelters,
quests, users, support tickets, and giveaways. Full documentation: [docs/CMS.md](../docs/CMS.md).

```bash
npm install
npm run dev                # needs NEXT_PUBLIC_BE_URL; use -p 3001 if the client is on 3000
npm run build && npm run start
npm test
```

Sign in with a Firebase account. Admin menus appear at backend permission level 3 or higher.
