NO LOGIN NEEDED (sign-in is optional)
Everything in Pawlegends plays without an account, so there is no demo account. All game files are inside the app, and it plays offline against computer-controlled bots from the first launch.

OPTIONAL SIGN-IN (guidelines 4.8, 5.1.1(v))
Tap "Sign in" in the top-right corner of the title screen (or Settings → Account). Choices: Sign in with Apple (shown first), Google, or email and password. Signing in saves wins and Treat Track progress to the player's account and enables friends and ranked play. Any Apple ID or email can be used to test it.
Account deletion: once signed in, tap your name in the top-right corner → Delete account (or Settings → Account → Delete account), confirm, and for an Apple account confirm the Apple prompt (we revoke the Apple token). The account is deleted on our server at once. Web alternative: https://pawlegends.app/account

HOW TO PLAY (about 7 minutes, never more than 11)
1. On the title screen tap "Play as <hero>" (Easy is the quickest).
2. Move by dragging on the left side of the screen. Tap the round skill buttons on the right; ATK is the basic attack.
3. Walk up a lane with your bots, knock down the dog towers, then the dogs' core to win.
"Change hero" opens the hero list (10 cat heroes). Settings is the gear icon.

PARTY PLAY (optional, needs the internet)
"Play with friends" creates a party and shows a 6-letter code; a second device joins with "Join with code". Friends play together on one team against bots; bots also fill empty seats. Chat is fixed quick-chat phrases and pings only: there is no free-text chat and no user-generated content.

NO PURCHASES
The iOS build has no in-app purchases, no ads, no external purchase links, no crypto or wallet features and no donations. Nothing in the app links to a store or website to buy anything.

GAME CONTENT UPDATES (guideline 2.5.2, 4.7)
The app checks tokentails.com on launch for a newer version of its own game files (HTML, JavaScript, images, sounds), signed and encrypted with our key, and applies it only on the title screen, never during a match. These updates run inside the system WKWebView and only change game content within the app's existing purpose (balance, bug fixes, new heroes). They never download or execute native code, and they never add purchases or change the app's main purpose. Any change that needs new permissions or native features goes through App Review as a new build. If an update does not start correctly, the app returns to the previous version automatically.

PRIVACY
No analytics, no tracking, no advertising identifier. Sign-in (optional) uses Firebase Authentication and keeps the email address, name and game progress for the account. Party play sends a random party key, a generated player name and match inputs to our game server only to run the match (details: https://pawlegends.app/privacy).
